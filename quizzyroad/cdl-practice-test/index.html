Commercial driver’s license

CDL knowledge practice tests

To get a commercial driver’s license you pass one or more knowledge tests before the skills test. Which ones you take depends on the license class you want and the endorsements you need. Each state publishes a CDL manual that covers every knowledge test, and our questions are written from that manual with a manual reference for every answer.

  • 406 questions
  • Pass mark: 80% (49 CFR 383.135 (eCFR))

Passing score and number of questions

Passing score: at least 80% correct on each knowledge test, set by federal rule (49 CFR 383.135 (eCFR)). Number of questions: this varies by state, so check the CDL manual from your state’s licensing agency.

Not sure which tests apply to you? Our guide CDL Classes, Endorsements and Restrictions Explained sums up the classes, the endorsements and the knowledge test each one needs.

Why there is one page per CDL test, not one per state

State CDL manuals are built on the same national model, so the CDL knowledge content is largely the same everywhere. Instead of fifty near-identical state pages, we keep one complete, carefully checked page for each test. If your state’s manual differs on a point, your state’s manual wins.

How to use these practice tests

  • Read the matching section of your state’s CDL manual first.
  • Use practice mode to see the explanation and the manual reference after each question.
  • Switch to exam mode when you can score well above 80% without help.
  • Review every missed question against the manual section we cite.
