Editorial policy

This page explains exactly how QuizzyRoad creates, checks and corrects its practice questions.

1. Official manuals only

Every question is based on one official manual, such as a state driver handbook or a state CDL manual published by the issuer. We work from the issuer’s file or from a faithful text copy of it, and record the manual’s title, issuer, edition, web address, the date we received it and a fingerprint (SHA-256) of the exact text we used, so we always know which version a question came from. When several states publish editions of the same model manual, as with the CDL manual, we cite the newest edition we have and also check each quote against the other editions. We never use outside knowledge to decide a correct answer: if the manual does not say it, we do not ask it.

2. Our own questions

Real test questions are not public. We write our own questions from the manual text and never copy, paraphrase or rewrite questions from other websites, apps or books.

3. AI-assisted drafting with a manual reference

Drafts are written with the help of AI tools, working from the extracted manual text. Every draft must store the manual, the numbered section (and the page, when the manual copy has page numbers) and a short exact quote (at most 25 words) that supports the correct answer.

4. Automatic quote check

A script checks that the quote appears word for word in the cited section (or on the cited page) of the manual text. A question whose quote cannot be found is rejected. Our website build fails if any question that has not been verified would be published.

5. Independent AI check

A separate AI review, which does not see the drafter’s reasoning, answers each question using only the cited part of the manual and flags any disagreement, ambiguous wording or more than one defensible answer.

6. Human review

A person reviews every flagged question and a random sample of the questions that passed, against the manual itself. Only questions marked verified are published. Explanations are written in our own words and show at most one short quoted phrase from the manual, always with its source.

7. Updates and error reports

When a state publishes a new edition of its manual, we re-check the questions based on it. If you think an answer is wrong, email quizzy.quest.planet@gmail.com with the test name, the question and, if you can, the manual section. We review every report, remove the question while we check it if needed, and fix it.

What we never claim

We never claim that our questions are the real or actual test questions, that our site is official, or that anyone is guaranteed to pass. Formats such as the number of questions and the passing score are shown only with a link to an official source.

QuizzyRoad is an independent study site and is not affiliated with any DMV, state agency or the FMCSA.
